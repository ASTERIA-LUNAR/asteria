# AI disclosure - ASTERIA

*Generated with Claude Code (Anthropic) under human direction.*

ASTERIA (Lunar South Pole Landing Site Navigator) is an entry for the NASA Space Apps Challenge 2026. The Challenge rules require that code and data produced with "super intelligence" (SI/AI) tools are acknowledged in descriptive text and metadata. This file describes where and how AI was used.

## Who did what

* **Direction**: a single team member set the goals, requirements, acceptance rules ("correctness first, never invent numbers, label approximations") and reviewed the results.
* **AI tool**: [Claude Code](https://www.anthropic.com/claude-code) (Anthropic), an AI coding assistant, generated the code, the data-processing scripts, the tests, the documentation and the text shown in the app, working in this project folder under that direction.
* **Verification**: the calculations were checked against independent references rather than trusted because an AI wrote them:
  * NASA/JPL Horizons (52 angle comparisons, 4 event times, a 10-case blind test on freshly fetched cases, one year of hourly rows at a custom point) - see VALIDATION_REPORT.md and the Validation tab.
  * NASA's published PGDA average-illumination maps (product 69) for the terrain horizons.
  * Direct DEM samples for the 3D terrain tiles (`tools/terrain3d.py check`).
  * VERIFY_YOURSELF.md explains how anyone can repeat these checks without programming.

## Images, graphics and audio

* **No image-generation or audio-generation model was used. There is no audio.**
* Graphics drawn in code written by Claude Code, marked visibly as AI-generated where shown:
  * the pixel-art rocket, Earth and Moon (loader and first-visit intro): label "AI-generated pixel art";
  * the simple box-shaped rover in the 3D view: label "AI-generated illustration".
* Removed in this round: a small SVG mark (circle, arc and dot) that Claude Code had drawn for the page header. It was too small to carry a visible watermark, so it was removed; the header now shows the name as text only.
* Map tiles (hillshade, slope, illumination) and the 3D terrain are renderings of NASA LOLA and PGDA data by the AI-written scripts. They show measured data, not generated imagery; their legends state the source and method (e.g. "synthetic lighting, not real illumination" for the hillshade).
* Charts, the sky view and the timeline are drawn live in the browser from computed values.
